# ChatterMost guide: earlier release records

These dated records were moved verbatim out of [`public/guides/chattermost.md`](../../public/guides/chattermost.md) so that the published guide keeps only its current release record. They describe the guide as it was on each date: "above" and "below" refer to that version of the guide, and the versions they name are not current. For current instructions read the [published guide](https://hivemagnus.com/guides/chattermost.md); for what each release changed, read the ChatterMost [release notes](https://github.com/ChefTaco/ChatterMost/releases).

Release update, 2026-11-12: [Hive 3.1.1](https://github.com/ChefTaco/hive/releases/tag/v3.1.1) pins ChatterMost 0.4.4, so the installation block now uses tag [`v0.4.4`](https://github.com/ChefTaco/ChatterMost/releases/tag/v0.4.4), commit `c777c786667e75ad7cf544b21d8c44bf2c3a3807`. The [agent runbook](https://github.com/ChefTaco/ChatterMost/blob/v0.4.4/AGENTS.md) block at that tag differs from 0.4.1 only in `VERSION`. The release attaches `chattermost-0.4.4.tar.gz` and `SHA256SUMS`; the archive's line matches the asset digest GitHub reports and the downloaded file, which contains `chattermost-0.4.4/`. The [container guide](https://github.com/ChefTaco/ChatterMost/blob/v0.4.4/docs/containers.md) lists 0.3.2, 0.3.3, 0.4.1 and 0.4.2 as reviewed upgrade sources for 0.4.4; container releases from 0.4.2 run Node 26 on a maintained glibc distribution.

Release update, 2026-11-12: [Hive 3.3.0](https://github.com/ChefTaco/hive/releases/tag/v3.3.0) pins ChatterMost 0.5.1, so the installation block now uses tag [`v0.5.1`](https://github.com/ChefTaco/ChatterMost/releases/tag/v0.5.1), commit `848d317aa9df6a8e94b318997d859aa8d68cacd2`. The [agent runbook](https://github.com/ChefTaco/ChatterMost/blob/v0.5.1/AGENTS.md) block at that tag differs from 0.4.4 only in `VERSION`. The release attaches `chattermost-0.5.1.tar.gz` and `SHA256SUMS`; the archive's line matches the asset digest GitHub reports and the downloaded file, which contains `chattermost-0.5.1/`. The [container guide](https://github.com/ChefTaco/ChatterMost/blob/v0.5.1/docs/containers.md) lists 0.3.2, 0.3.3, 0.4.1, 0.4.2, 0.4.4 and 0.4.5 as reviewed upgrade sources for 0.5.1. Since 0.5.0, Oathweave tokens are checked by the suite's shared verifier with ChatterMost's existing rules (user tokens only, no clock tolerance, an exact `chattermost:session` permission and online session checks), and the service adds `/health/live` and `/health/ready`. Because ChatterMost is internet-facing, it generates its own request ID for every request rather than accepting one from the caller. Mattermost error responses are unchanged.

Release update, 2026-11-13: [Hive 3.7.0](https://github.com/ChefTaco/hive/releases/tag/v3.7.0) pins ChatterMost 0.5.2, so the installation block now uses tag [`v0.5.2`](https://github.com/ChefTaco/ChatterMost/releases/tag/v0.5.2), commit `8141ea0af55c4f33efa92a9fdeb9f9a96d0c06a7`. The [agent runbook](https://github.com/ChefTaco/ChatterMost/blob/v0.5.2/AGENTS.md) block at that tag differs from 0.5.1 only in `VERSION`, and the release attaches `chattermost-0.5.2.tar.gz` and `SHA256SUMS`; the archive was not downloaded or installed for this update. The [container guide](https://github.com/ChefTaco/ChatterMost/blob/v0.5.2/docs/containers.md) lists 0.3.2, 0.3.3, 0.4.1, 0.4.2, 0.4.4, 0.4.5 and 0.5.1 as reviewed upgrade sources for 0.5.2.

Release update, 2026-11-14: [Hive 3.8.0](https://github.com/ChefTaco/hive/releases/tag/v3.8.0) pins ChatterMost 0.6.1, so the installation block now uses tag [`v0.6.1`](https://github.com/ChefTaco/ChatterMost/releases/tag/v0.6.1), commit `ff218472096906fbf9770f3061d995f0c9c39953`. The [agent runbook](https://github.com/ChefTaco/ChatterMost/blob/v0.6.1/AGENTS.md) block at that tag differs from 0.5.2 only in `VERSION`, and the release attaches `chattermost-0.6.1.tar.gz` and `SHA256SUMS`; the archive was not downloaded or installed for this update. The [container guide](https://github.com/ChefTaco/ChatterMost/blob/v0.6.1/docs/containers.md) lists 0.3.2, 0.3.3, 0.4.1, 0.4.2, 0.4.4, 0.4.5, 0.5.1 and 0.5.2 as reviewed upgrade sources for 0.6.1. Per Hive's release notes, 0.6.1 closes a WebSocket when its credential ends and tightens channel, post and team permissions; its `v0.6.0` tag is not a release.

Release update, 2026-11-15: [Hive 3.9.3](https://github.com/ChefTaco/hive/releases/tag/v3.9.3) pins ChatterMost 0.6.4, so the installation block now uses tag [`v0.6.4`](https://github.com/ChefTaco/ChatterMost/releases/tag/v0.6.4), commit `836e4e7d8d10e8076f4da8c3a051b4f9fb15f9e4`. The [agent runbook](https://github.com/ChefTaco/ChatterMost/blob/v0.6.4/AGENTS.md) block at that tag differs from 0.6.1 only in `VERSION`, and the release attaches `chattermost-0.6.4.tar.gz` and `SHA256SUMS`; the archive was not installed for this update. The [container guide](https://github.com/ChefTaco/ChatterMost/blob/v0.6.4/docs/containers.md) adds 0.6.1 to the reviewed upgrade sources. Per its [release notes](https://github.com/ChefTaco/ChatterMost/blob/v0.6.4/docs/releases.md), 0.6.4 moves to `@hivemagnus/hive-common` 0.5.0, refuses an Oathweave token without a `roles` array before the online session check and adds `X-Request-Id` to the health responses; it adds no database migration. Its `v0.6.2` and `v0.6.3` tags are not releases.

Release update, 2026-11-16: [Hive 3.11.0](https://github.com/ChefTaco/hive/releases/tag/v3.11.0) pins ChatterMost 0.7.0 and its matching migrator, tag [`v0.7.0`](https://github.com/ChefTaco/ChatterMost/releases/tag/v0.7.0), commit `3e14259c6ce1caebb7baddbe370ee8447d9c4386`. The installation block now uses `VERSION=0.7.0` and otherwise matches the [agent runbook](https://github.com/ChefTaco/ChatterMost/blob/v0.7.0/AGENTS.md#installation-runbook-for-agents) at that tag; the release attaches `chattermost-0.7.0.tar.gz` and `SHA256SUMS`. The provisioning API above follows the [release notes](https://github.com/ChefTaco/ChatterMost/blob/v0.7.0/docs/releases.md#changes-in-070). No installation command was run for this update.
