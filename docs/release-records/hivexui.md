# HiveXUI guide: earlier release records

These dated records were moved verbatim out of [`public/guides/hivexui.md`](../../public/guides/hivexui.md) so that the published guide keeps only its current release record. They describe the guide as it was on each date: "above" and "below" refer to that version of the guide, and the versions they name are not current. For current instructions read the [published guide](https://hivemagnus.com/guides/hivexui.md); for what each release changed, read the HiveXUI [changelog](https://github.com/ChefTaco/HiveXUI/blob/main/CHANGELOG.md).

Release update, 2026-11-12: [Hive 3.3.0](https://github.com/ChefTaco/hive/releases/tag/v3.3.0) pins HiveXUI 0.4.0, tag [`v0.4.0`](https://github.com/ChefTaco/HiveXUI/releases/tag/v0.4.0), commit `96dd09e5b6b6989d73a738a0c0c26bdb2c4be50d`. Compared with 0.2.7, its [README](https://github.com/ChefTaco/HiveXUI/blob/v0.4.0/README.md) keeps the same sections and build commands and now notes that every page of the earlier Magnus dashboard has an equivalent, apart from the deliberate omissions listed in the Magnus module. Per its [changelog](https://github.com/ChefTaco/HiveXUI/blob/v0.4.0/CHANGELOG.md), 0.3.0 added the Embermend section, and 0.4.0 sends an `x-request-id` with every API request, presents every section through the shared UI kit, names audit and incident pages by product, derives navigation and deep links from one route table without changing any address, adds automated WCAG 2.1 A/AA checks and updates the Magnus agent upgrade drawer.

The build commands were not re-run for this update.

Release update, 2026-11-17: [Hive 3.12.0](https://github.com/ChefTaco/hive/releases/tag/v3.12.0) pins HiveXUI 0.10.0, tag [`v0.10.0`](https://github.com/ChefTaco/HiveXUI/releases/tag/v0.10.0), commit `39ae4e0304159822d0eb37ba451ff687a44d87f1` (Hive 3.9.7 to 3.11.2 pinned 0.9.2). The Cindertrace sign-in paragraph above follows its [changelog](https://github.com/ChefTaco/HiveXUI/blob/v0.10.0/CHANGELOG.md) and [README](https://github.com/ChefTaco/HiveXUI/blob/v0.10.0/README.md); 0.10.0 also labels the four suite audit exports Cindertrace collects on its Sources page and reads one vendored Cindertrace browser contract. The README at that tag still lists Cindertrace's console as a retained UI until Cindertrace ships HiveXUI in local mode; Cindertrace 0.8.0, which Hive 3.12.0 pins, ships it and removes the console, so the retained-UI paragraph above names Magnus's standalone console only. Per Hive's [changelog](https://github.com/ChefTaco/hive/blob/v3.12.0/CHANGELOG.md), its vendored Magnus browser contract is byte-identical to Magnus 3.1.3's. The build commands are unchanged and were not re-run for this update.

Release update, 2026-11-18: [Hive 3.12.3](https://github.com/ChefTaco/hive/releases/tag/v3.12.3) pins HiveXUI 0.10.1, tag [`v0.10.1`](https://github.com/ChefTaco/HiveXUI/releases/tag/v0.10.1), commit `ff54286a049124bcbd3e025103aa6df6ee20f43f`. Per its [changelog](https://github.com/ChefTaco/HiveXUI/blob/v0.10.1/CHANGELOG.md), 0.10.1 requires `@hivemagnus/hive-common` 0.5.1, whose error reader cleaned a product's error code with a regular expression that was quadratic on a code of many underscores between two other characters, so one hostile or broken error answer could stall the tab for seconds; it now does this in linear time. The [README](https://github.com/ChefTaco/HiveXUI/blob/v0.10.1/README.md) at that tag now names Magnus's standalone console as the only retained UI, as the paragraph above does, so the README and Theme links point at `v0.10.1`. The vendored Magnus browser contract is unchanged from 0.10.0. The build commands are unchanged and were not re-run for this update.

Release update, 2026-11-19: [Hive 3.12.5](https://github.com/ChefTaco/hive/releases/tag/v3.12.5) pins HiveXUI 0.10.2, tag [`v0.10.2`](https://github.com/ChefTaco/HiveXUI/releases/tag/v0.10.2), commit `24cdfab54cb243858d433f74572883bbad2404a4` (Hive 3.12.3 and 3.12.4 pinned 0.10.1). Per its [changelog](https://github.com/ChefTaco/HiveXUI/blob/v0.10.2/CHANGELOG.md), 0.10.2 sends a UUID task ID from the Fleet **Submit test** form and requires nginx 1.30.7 or later in the image. Its vendored browser contracts are unchanged from 0.10.1. The header links, the README link and the suite sentence now use `v0.10.2`. No installation command was run for this update.
