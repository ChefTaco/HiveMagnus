# Magnus guide: earlier release records

These dated records were moved verbatim out of [`public/guides/magnus.md`](../../public/guides/magnus.md) so that the published guide keeps only its current release record. They describe the guide as it was on each date: "above" and "below" refer to that version of the guide, and the versions they name are not current. For current instructions read the [published guide](https://hivemagnus.com/guides/magnus.md); for what each release changed, read the Magnus [changelog](https://github.com/ChefTaco/magnus/blob/main/CHANGELOG.md).
