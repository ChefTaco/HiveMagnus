# Oathweave guide: earlier release records

These dated records were moved verbatim out of [`public/guides/oathweave.md`](../../public/guides/oathweave.md) so that the published guide keeps only its current release record. They describe the guide as it was on each date: "above" and "below" refer to that version of the guide, and the versions they name are not current. For current instructions read the [published guide](https://hivemagnus.com/guides/oathweave.md); for what each release changed, read the Oathweave [changelog](https://github.com/ChefTaco/Oathweave/blob/main/CHANGELOG.md).

Release update, 2026-11-13: [Hive 3.7.0](https://github.com/ChefTaco/hive/releases/tag/v3.7.0) pins Oathweave 2.2.0, tag [`v2.2.0`](https://github.com/ChefTaco/Oathweave/releases/tag/v2.2.0), commit `3b6d7df399b72f16630b6af16ca3d49040eae2ac`. The container example now uses the `2.1.2` image, the version the [server README](https://github.com/ChefTaco/Oathweave/blob/v2.2.0/apps/iam-core/README.md) at that tag names; its environment files and commands are otherwise identical to the reviewed 2.0.1 example, and it was not re-run with the new image. Each release is tagged with its exact version, so replace `2.1.2` to run another one.

Release update, 2026-11-14: [Hive 3.8.0](https://github.com/ChefTaco/hive/releases/tag/v3.8.0) pins Oathweave 2.3.0, tag [`v2.3.0`](https://github.com/ChefTaco/Oathweave/releases/tag/v2.3.0), commit `d2ac3c08c8a55200160321f51bd807515bb0d249`. The container example now uses the `2.3.0` image, as the [server README](https://github.com/ChefTaco/Oathweave/blob/v2.3.0/apps/iam-core/README.md) at that tag does; its environment files and commands are otherwise unchanged, and it was not re-run with the new image. The sign-in and client address rules above follow the [changelog](https://github.com/ChefTaco/Oathweave/blob/v2.3.0/CHANGELOG.md) and the server README's client address section at that tag.

Release update, 2026-11-17: [Hive 3.11.2](https://github.com/ChefTaco/hive/releases/tag/v3.11.2) pins Oathweave 2.3.1, tag [`v2.3.1`](https://github.com/ChefTaco/Oathweave/releases/tag/v2.3.1), commit `e13679c39c2265f28908cb225f58e38164c3f9d9`. The container example now uses the `2.3.1` image, as the [server README](https://github.com/ChefTaco/Oathweave/blob/v2.3.1/apps/iam-core/README.md) at that tag does; its environment files and commands are otherwise unchanged, and it was not re-run with the new image. Per the [changelog](https://github.com/ChefTaco/Oathweave/blob/v2.3.1/CHANGELOG.md), the server is unchanged: the in-repository SDK (`packages/iam-sdk`) now expects the server's default issuer, `hive-iam`, when a verifier sets none, so a service whose server signs with another `JWT_ISSUER` must set `issuer` to it. The npm package `@hivemagnus/hive-iam-sdk` 1.0.3 is retired and keeps the old `iam-core` default. Per Hive's [UPGRADING](https://github.com/ChefTaco/hive/blob/v3.11.2/UPGRADING.md#suite-3112-product-maintenance-releases), an installation needs no change.

Release update, 2026-11-20: [Hive 3.12.9](https://github.com/ChefTaco/hive/releases/tag/v3.12.9), tag `v3.12.9`, commit `353eb340634ae2fe8d63ae97360f701b9acb2a7b`, pins Oathweave 2.3.2, tag [`v2.3.2`](https://github.com/ChefTaco/Oathweave/releases/tag/v2.3.2), commit `bdeccac4f4975ed47aeef16e009f5cd5b23b9255` (Hive 3.11.2 to 3.12.7 pinned 2.3.1). The container example now uses the `2.3.2` image, as the [server README](https://github.com/ChefTaco/Oathweave/blob/v2.3.2/apps/iam-core/README.md) at that tag does; its environment files and commands are otherwise unchanged, and it was not re-run with the new image. Per the [changelog](https://github.com/ChefTaco/Oathweave/blob/v2.3.2/CHANGELOG.md), 2.3.2 overrides the npm package `effect` to 3.22.1, which fixes CVE-2026-121707 (a regular-expression denial of service in `Schema.TemplateLiteral`), so the image no longer ships 3.20.0; its only consumer is the Prisma CLI's configuration loader used for migrations, not request handling. It has no database migration and no settings change. The client address paragraph above adds the `TRUSTED_PROXY_IPS` setting of [Hive 3.12.7](https://github.com/ChefTaco/hive/releases/tag/v3.12.7)'s controller, per its [changelog](https://github.com/ChefTaco/hive/blob/v3.12.7/CHANGELOG.md) and [UPGRADING](https://github.com/ChefTaco/hive/blob/v3.12.7/UPGRADING.md#suite-3127-oathweave-client-addresses). No installation command was run for this update.

The container example now uses the `2.3.3` image, as the [server README](https://github.com/ChefTaco/Oathweave/blob/v2.3.3/apps/iam-core/README.md) at that tag does; its environment files and commands are otherwise unchanged, and it was not re-run with the new image. The fresh-installation paragraph follows the [changelog](https://github.com/ChefTaco/Oathweave/blob/v2.3.3/CHANGELOG.md) and Hive's [UPGRADING](https://github.com/ChefTaco/hive/blob/v3.14.0/UPGRADING.md#suite-3140-ardent-execution-recovery-lineage-and-artifact-transfer-v2).
